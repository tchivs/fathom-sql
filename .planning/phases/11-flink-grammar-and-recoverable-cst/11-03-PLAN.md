Purpose: Deliver the DDL slice. FLINK-03 and FLINK-04 are planned together because parse_flink_create_table is a single production spanning both: FLINK-03 contributes the DDL statement-family entry (dispatch + CATALOG/DATABASE/VIEW/FUNCTION families + the TABLE family entry), and FLINK-04 contributes the CREATE TABLE complex body. The Flink DDL parser is written from the pinned SqlCreateTable (parserImpls.ftl:1585-1712) with independent productions — never Doris reuse. Every statement family ships positive/negative/incomplete/recovery fixtures × strict/editor snapshots and lossless-replay assertions.
Output: parse_flink_create/alter/drop dispatch + the per-family DDL productions, parse_flink_create_table (four-column body + WATERMARK + constraints + table-level clauses + LIKE/AS), is_flink_create_table_clause_boundary, DDL/CREATE TABLE flink-grammar snapshots, and the register rows.
</objective>
