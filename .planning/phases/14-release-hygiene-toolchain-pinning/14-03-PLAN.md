<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Matrix runner → uploaded artifact | 每个平台把 binary 和 runtime-observed evidence 交给 artifact storage。 |
| Release checkout → qualification commands | 当前 tag/dispatch checkout 在 exact toolchain 下接受九项发布资格检查。 |
| Artifact storage → publication job | 下载内容可能缺失、重复、被替换或包含未知平台记录。 |
| Publication job → GitHub Release | 只有通过 dependencies 和 aggregate validation 的内容获得 contents write/upload。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-13 | Spoofing | Per-platform evidence | high | mitigate | helper 生成 observed OS/arch/digests/raw version；validator 严格 target/arch/lock 一致性和 exact set。 |
| T-14-14 | Tampering | Downloaded artifacts | high | mitigate | 不信任合并 glob；拒绝 missing/duplicate/unknown/schema/digest/identity mismatch，成功前不写 aggregate。 |
| T-14-15 | Elevation of Privilege | Publication permission/DAG | high | mitigate | contents write 仅 publication job；exact `needs` 绑定 build+release-gates，validator 在 upload 前。 |
| T-14-16 | Repudiation | Toolchain provenance | medium | mitigate | 每平台记录 + aggregate 保留 raw version、runner facts、archive digests and lock identity。 |
| T-14-17 | Denial of Service | Gate or platform failure | medium | accept | 任何失败应阻断 publication；没有 bypass 是 TC-02 的预期可用性取舍。 |
| T-14-18 | Tampering | Gate topology/commands | high | mitigate | 九个权威命令 exact-once，no matrix duplication/历史状态/skip/tolerance；结构 verify 锁定命令与 needs。 |
</threat_model>
