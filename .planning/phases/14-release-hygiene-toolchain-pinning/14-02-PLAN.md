## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Committed lock → shell helpers | JSON identity 驱动平台选择、URL、digest 与 raw version 断言。 |
| Network/archive → runner filesystem | 未信任下载进入解包和执行路径。 |
| Helper → GitHub Actions PATH/evidence | 只有已验证安装可以影响后续 build/test，并输出 observation。 |
| CI YAML/comments → naming gate | 配置和注释属于被扫描产品文本。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-07 | Tampering | Lock parsing/platform selection | high | mitigate | 严格 schema、唯一 role、observed OS/arch 与 explicit target 三方匹配；无环境默认或 URL 推断。 |
| T-14-08 | Tampering/Elevation | Download/extraction | high | mitigate | archive+sidecar 双下载、locked/vendor digest 一致、安全 member/layout 检查、隔离解包，验证前不发布 PATH。 |
| T-14-09 | Spoofing | Reported toolchain identity | high | mitigate | 完整 raw output byte equality；observation 从实际 OS/arch 与已验证 archive 生成。 |
| T-14-10 | Denial of Service | Network/vendor failure | medium | accept | CI 正确失败而非回退；D-03 的完整性优先于可用性。 |
| T-14-11 | Tampering | Ordinary CI gate commands | medium | mitigate | 迁移只替换 bootstrap，自动 verify 要求九个权威 gate 命令仍在，scanner/allowlist 不改。 |
| T-14-12 | Repudiation | User/runtime tree changes | high | mitigate | 精确三文件提交与 scoped status；未知状态只报告、不清除。 |
