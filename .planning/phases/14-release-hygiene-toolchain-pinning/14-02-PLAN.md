## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Committed lock → shell helpers | JSON identity 驱动平台选择、URL、digest 与 raw version 断言。 |
| Network/archive → runner filesystem | 未信任下载进入解包和执行路径。 |
| Helper → GitHub Actions PATH/evidence | 只有已验证安装可以影响后续 build/test，并输出 observation。 |
| CI YAML/comments → naming gate | 配置和注释属于被扫描产品文本。 |
| Temporary push workflow/run → downloaded evidence | 唯一的 off-default push run 必须绑定 workflow path/name、branch、probe SHA、implementation SHA 和 event，且远程 ref 在证据下载校验前保留。 |
