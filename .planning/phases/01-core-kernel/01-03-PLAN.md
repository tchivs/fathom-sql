## Trust Boundaries
| Boundary | Description |
|---|---|
| Caller/editor → recovery parser | Untrusted incomplete, malformed, deeply nested, or invalidly encoded bytes may target loops or resource exhaustion. |
| Diagnostic/CST result → host | Error material and coordinates will later cross adapters and must remain unambiguous and source-faithful. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-09 | Denial of Service | Recovery synchronization | high | mitigate | Enforce progress-or-error and finite recovery/diagnostic caps; retain remainder once capped. |
| T-01-10 | Denial of Service | Recursive nesting | high | mitigate | Track recursion depth, stop deterministically, and emit one bounded resource diagnostic. |
| T-01-11 | Tampering | Strict/editor status | medium | mitigate | Use one CST family with explicit validity/recovered fields and test identical malformed inputs in both modes. |
| T-01-12 | Tampering | Statement identity/span | medium | mitigate | Validate byte spans against one source and assign source-order zero-based IDs per snapshot (Q4). |
| T-01-13 | Information Disclosure | Error/skipped retention | low | accept | Replay exposes only caller-supplied bytes; the core has no secret store or I/O access. |
| T-01-SC | Tampering | Package installation | low | accept | No package installation task exists and no third-party runtime is introduced. |
</threat_model>
