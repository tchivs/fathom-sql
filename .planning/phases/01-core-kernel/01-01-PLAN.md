| T-01-02 | Tampering | Profile classification | high | mitigate | Require exactly the three public profiles and retain release/minor metadata; reject unknown profiles without generic fallback (Q2, D-07). |
| T-01-03 | Tampering | Raw-byte/encoding handling | high | mitigate | Preserve invalid runs as source-backed ERROR/unknown tokens with stable encoding diagnostics and original spans (Q3). |
| T-01-04 | Tampering | Toolchain reproducibility | medium | mitigate | Pin official v0.10.5 line, record exact `moon version`, and forbid floating latest or invented dependencies (Q1). |
| T-01-SC | Tampering | Package installation | low | accept | No package installation task exists; only the pinned MoonBit toolchain and local core primitives are used. |
