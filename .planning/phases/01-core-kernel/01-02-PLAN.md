| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-05 | Tampering | Root source payload and node spans | high | mitigate | Serialize original bytes once at root; validate every descendant span against that source and reject unusable transport omission. |
| T-01-06 | Tampering | Diagnostic code and statement identity | high | mitigate | Emit only `DORIS-PARSE-###` codes and deterministic zero-based `u32` IDs per snapshot (Q4). |
| T-01-07 | Denial of Service | Pratt/parser recursion | high | mitigate | Keep progress-or-error hooks and carry finite limits into the result contract for 01-03. |
| T-01-08 | Information Disclosure | Replay output | low | accept | Replay exposes only caller-supplied source; no secret store, filesystem, network, or FE exists in the core. |
| T-01-SC | Tampering | Package installation | low | accept | No package installation task exists and no third-party runtime is introduced. |
