## threat_model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 调用方 source bytes → analyzer | 未信任 SQL 输入；二次解析只消费 CST 叶子（整 token 字节判定），永不重扫 leaf 内部字节 |
| catalog（含 db 作用域表） → analyzer | T-02-42：catalog 不可信；db_tables/table 元数据只被 analyzer 消费 |
| 作用域栈内部 | CTE/子查询帧隔离错误会导致跨作用域误导性绑定（Spoofing） |
