## threat_model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 调用方 source bytes + overrides JSON → fathom_lint_v1 | 未信任 SQL + 配置；overrides 必须结构化解析（非法 JSON → 错误，非默认回退） |
| binding lint_result_json → 宿主 | findings/output/diagnostics 在此序列化；消息结构化编码 + 长度上限 |
| fix 模式 output → 宿主 | 修复结果必须 round-trip 干净（D-03 防御纵深），拒绝时不含部分编辑字节 |

### STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-03-01 | Tampering | overrides JSON 注入/畸形 | high | mitigate | 结构化 JSON 解析，非数组/非法结构 → 结构化错误（绝不当默认注册表静默吞掉）；ASVS V5 输入校验 |
| T-06-03-02 | Tampering | SQL 字符串注入 lint 消息/JSON | medium | mitigate | findings/诊断消息结构化编码 + 长度上限（引用源码截断保留 span）；不把原始字节拼进 message |

| T-06-03-SC | Tampering | npm/pip/cargo 安装 | low | accept | 零新增外部依赖 |
