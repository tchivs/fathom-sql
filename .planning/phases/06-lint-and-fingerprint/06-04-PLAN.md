## threat_model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI stdin/file → run_lint/run_fingerprint | 未信任 SQL；ParseLimits 封顶，D-39 退出码承载失败 |
| run_fingerprint stdout → 终端/管道 | 指纹必须十进制 string（2^53 精度），字节精确 write_fd |
| parity 三目标 fixture → compare_backends.py | 快照回归门禁；fingerprint 命名空间独立 |

### STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04-01 | Tampering | `--rule` 值注入（code/severity） | medium | mitigate | whitelist 校验 code 存在于注册表 + severity 经 from_id/off；非法 → UnknownValue → exit 2（D-04） |
| T-06-04-02 | Tampering | fingerprint stdout 精度 | high | mitigate | `fingerprint.to_string()` 十进制 string + 字节精确 write_fd(1)；绝不 number 形式（Pitfall 3） |
| T-06-04-03 | Tampering | --fix 对 error 树部分编辑 | high | mitigate | D-33 拒绝 → exit 1 + FATHOM-LINT-000（run_lint 不绕过 apply_fixes 安全闸） |
| T-06-04-04 | Spoofing | parity 快照漂移掩盖回归 | medium | mitigate | compare_backends.py + parity/__snapshot__ fingerprint 命名空间；fingerprint 十进制 string 三目标一致断言 |
| T-06-04-05 | DoS | CLI 超大输入 | medium | mitigate | ParseLimits（api 层 8 MiB）+ run_lint/run_fingerprint 线性处理 |
| T-06-04-SC | Tampering | npm/pip/cargo 安装 | low | accept | 零新增外部依赖 |
