  <action>
Create `npm/` with:
- `package.json`: name `@fathom/sql`, version `1.0.0`, `"type": "module"`, `files: ["binding.js","binding.wasm","index.mjs","index.d.ts","capabilities.json","README.md"]`, `exports: { ".": { "types": "./index.d.ts", "import": "./index.mjs" } }`, `engines: { node: ">=18" }`, license Apache-2.0.
- `index.mjs`: ESM wrapper importing the built `binding.js` and exposing typed functions — `parse(raw, dialect, profile, mode)`, `format(raw, dialect, profile, mode, options)`, `complete(raw, dialect, profile, cursorByte)`, `lint(...)`, `fingerprint(...)`, `lineage(raw, dialect, profile, mode, catalog?)`, `dialects()`, `capabilities()` — each calling the corresponding `fathom_*_v1` byte export with UTF-8 encode/decode (TextEncoder/TextDecoder) and JSON parsing; errors surface as decoded envelopes.
- `index.d.ts`: TypeScript declarations mirroring the wrapper surface (Bytes as Uint8Array|string, structured option/result types; use `unknown`-typed JSON results with documented envelope shapes).
- `README.md`: Node and browser usage, build-from-source note, link to docs.
- `build.mjs`: runs `moon build --target js binding` and `moon build --target wasm binding` (release), copies `_build/js/release/build/binding/binding.js` → `npm/binding.js` and `_build/wasm/release/build/binding/binding.wasm` → `npm/binding.wasm`, generates `npm/capabilities.json` by importing the built binding and calling `fathom_capabilities_v1()`, then runs `npm pack` in `npm/` (output tarball for the smoke test).
- `.gitignore` inside npm/: ignore generated `binding.js`, `binding.wasm`, `capabilities.json`, and `*.tgz` (artifacts are build outputs).
  </action>

  </verify>
