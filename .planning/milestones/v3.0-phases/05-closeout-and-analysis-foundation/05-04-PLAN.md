## threat_model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 调用方 source bytes → analyzer | 未信任 SQL；函数调用识别只基于 CST 叶子整 token 字节 |
| catalog（含 functions 注册表） → analyzer | T-02-42：函数元数据（param_types/return_type）不可信、只被 analyzer 消费；作不透明 String 处理 |
| analyzer 诊断 → 调用方 | 独立通道；ambiguous/arity 等诊断绝不进入语法 valid 通道（ANLY-01） |

### STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04-01 | Tampering | functions 注册表元数据（param_types/return_type/name）注入 | medium | mitigate | T-02-42：函数元数据作不透明 String，绝不执行、绝不格式化进语法通道；data_type 仅从 FunctionInfo.return_type 拷贝到 Binding |
| T-05-04-02 | Spoofing | 函数调用与限定名列的误判（`f()` vs `t.col`） | medium | mitigate | 识别规则：`name(` 且深度 0、前序非 `.`、非 FROM 上下文；白盒/集成用例锁定 |
| T-05-04-03 | Tampering | 类型诊断泄漏进语法 valid 通道 | medium | mitigate | ANLY-01：analyzer 诊断独立通道；test/analyzer_test.mbt 逐字段相等断言保持 |
| T-05-04-04 | DoS | 病态嵌套实参/函数调用 | medium | mitigate | 复用既有括号深度上限（128）；实参计数基于深度 0 逗号，无额外递归 |
| T-05-04-SC | Tampering | 依赖安装 | low | accept | 本阶段零新增依赖（D-21）；无 npm/pip/cargo 安装面 |
