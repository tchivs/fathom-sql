## threat_model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 调用方 source bytes → analyzer | 未信任 SQL 输入经 parser 产 CST；analyzer 只消费 `@syntax.SyntaxNode` read-view + 调用方 bytes（D-21） |
| 调用方 catalog → analyzer | catalog 元数据是 caller-injected 且不可信（T-02-42）；只被 analyzer 消费，绝不进入 parser/syntax valid 通道（ANLY-01） |
| analyzer 诊断 → 调用方 | 独立诊断通道（AnalysisDiagnostic），与 FATHOM-PARSE 语法通道完全隔离 |

### STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-02-01 | DoS | select_parser 括号深度递归 | medium | mitigate | 子句切分只对整 token 字节计 `(`/`)`；括号深度上限（默认 128，镜像 parser max_recursion_depth），超限产出 "requires-complete-parse" 诊断而非递归 |
| T-05-02-02 | Tampering | catalog 元数据 name/data_type | medium | mitigate | T-02-42：catalog 不可信、只被 analyzer 消费；name/data_type 一律作不透明 String，绝不执行、绝不格式化进语法通道；ANLY-01 测试（test/analyzer_test.mbt:51-63）持续断言 |
| T-05-02-03 | Spoofing | 错误/恢复树上的误导性 binding | medium | mitigate | analyze 入口检查 body kind；Error/Missing 树产出空 bindings + "requires-complete-parse" 诊断（镜像 formatter D-33 refusal），绝不 panic |
| T-05-02-04 | Tampering | 分析诊断泄漏进语法 valid 通道 | medium | mitigate | ANLY-01：analyzer 诊断是独立通道，语法 valid 与 catalog 无关；test/analyzer_test.mbt 逐字段相等断言锁定 |
| T-05-02-SC | Tampering | 依赖安装 | low | accept | 本阶段零新增依赖（D-21 约束下 analyzer 仅 import syntax）；无 npm/pip/cargo 安装面 |
