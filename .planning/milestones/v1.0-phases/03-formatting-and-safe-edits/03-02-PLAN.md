## Trust Boundaries

| Boundary | Description |
|---|---|
| Untrusted SQL input → list layout | Adversarial list nesting must not trigger recursive reflow or quadratic work; layout is a single forward pass. |
| Layout decisions → parse validity | A comma placement (especially last-item trailing comma) can change parse validity; only the reparse probe decides. |
| Comment/hint leaves → layout | Comment bytes must never be rewritten, dropped, or moved across a line boundary they did not already have. |
