# Milestone v1.0: milestone — Doris SQL Parser SDK

**Status:** ✅ SHIPPED 2026-08-05
**Phases:** 1-4
**Total Plans:** 19 (4+6+4+5)

## Overview

第一个可发布里程碑:以 MoonBit 单一核心实现 Doris SQL 解析 SDK —— 无损 CST 内核、SELECT/DML/DDL 工业级语法覆盖、版本化官方文档语料库、可配置无损格式化与 `doris-sql format` CLI、Native LSP、JS/Wasm facade、Web/Monaco 演示与 VS Code 扩展。27/27 v1 需求全部验证;所有交付离线可用,不依赖 Doris FE。

## Phases

### Phase 1: Core Kernel

**Goal**: Consumers can parse an explicitly selected Doris 2.1, 3.x, or 4.x profile into a lossless, recoverable CST with precise diagnostics and industrial SELECT/expression coverage, entirely offline.
**Depends on**: Nothing (first phase)
**Plans**: 4 plans

Plans:

- [x] 01-01: establish the pinned source, token, and lexer tracer
- [x] 01-02: build the lossless CST, parser API, and exact replay path
- [x] 01-03: add bounded strict/editor recovery and stable diagnostics
- [x] 01-04: cover industrial SELECT and versioned corpus fixtures

**Details:**
- SourceText (raw bytes, checked half-open spans, LineIndex), token/trivia 保留,Pratt 表达式,语句级 panic-mode 恢复,DORIS-PARSE-001..006 诊断命名空间,ParseLimits(8MiB/1M tokens/递归/恢复/诊断上限),strict/editor 双模式,`print_lossless(parse(x))==x` 契约。

### Phase 2: Doris Completeness and Corpus

**Goal**: Users can parse version-supported Doris scripts and warehouse-specific DML/DDL with localized errors, while maintainers and consumers can inspect reproducible coverage and the syntax-only/analyzer boundary.
**Depends on**: Phase 1
**Plans**: 6 plans

Plans:

- [x] 02-01: keyword-first DML dispatch with INSERT tracer, UPDATE/DELETE, 4.x-gated MERGE, and unsupported-statement nodes
- [x] 02-02: full CREATE TABLE body, VIEW/CTAS/LIKE, INDEX and sync MATERIALIZED VIEW with version gates
- [x] 02-03: data-driven three-layer keyword classification with keywords.tsv audit report
- [x] 02-05: analyzer package with minimal catalog and statement-level accessors
- [x] 02-04: DML/DDL metadata contract, expanded fixture corpus, and CORPUS-REPORT.md generator
- [x] 02-06: SQLGlot local differential runner and FE/Nereids manual script

**Details:**
- DORIS-PARSE-007 unsupported-statement;MERGE 4.x-only gate;CREATE TABLE ORDER BY 4.1.0 / BUCKETS AUTO 2.1 gates;三层关键字分类(116 行 keywords.tsv);manifest 44 行 fixture 全 unavailable-offline 诚实标注;corpus_test.mbt 嵌入式 oracle 关闭 Phase 1 磁盘消费 gap;CORPUS-REPORT.md --check 模式;SQLGlot 30.14.0 差分 44 行 advisory_only;analyzer/ 独立包,parser 负向 gate。

### Phase 3: Formatting and Safe Edits

**Goal**: Users can choose exact source replay or a deterministic, configurable, comment-preserving canonical rendering and invoke it safely from the `doris-sql format` command.
**Depends on**: Phase 2
**Plans**: 4 plans

Plans:

- [x] 03-01: formatter core tracer with FormatOptions, refusal walk, and api.format_text shared entry
- [x] 03-02: full canonical layout: per-family clause tables, list measure-then-break, comma styles, script layout, comment/hint attachment
- [x] 03-03: all six option dimensions functional, 44-row corpus harness, option-matrix idempotence, never-panic boundary suite
- [x] 03-04: doris-sql format CLI: libc FFI, hand-rolled args with required --profile, exit 0/1/2, moon-test suite + binary smoke

**Details:**
- FormatOptions 六维(KeywordCase/indent/line_width/comma/newline/trailing);measure-then-break 构造性幂等;DORIS-FORMAT-001 绝对拒绝(error 树空输出,不掩盖解析诊断);44 行 corpus harness + 96 组合选项矩阵幂等;CLI 手写 libc FFI(NUL 终止修复);review 修复:indent 上限 64、parenthesis_depth O(n²)→O(1)(8k 项 8s→70ms)。

### Phase 4: Ecosystem and Multi-Target Delivery

**Goal**: Editors, web applications, and automation can use one versioned Doris parser through Native LSP/CLI and stable Wasm/JavaScript facades with consistent results across targets.
**Depends on**: Phase 3
**Plans**: 5 plans

Plans:

- [x] 04-00: create shared schema, parity, LSP, Web, and VS Code harnesses
- [x] 04-01: freeze serialized schema/coordinates and deliver Native LSP diagnostics/formatting tracer
- [x] 04-02: add syntax-aware completion and protocol/version hardening
- [x] 04-03: expose JS/linear-Wasm facades and prove Native/JS/Wasm parity
- [x] 04-04: deliver the approved offline Web/Monaco demonstration and VS Code client

**Details:**
- lsp/ Native 服务器(Content-Length framing 16KB/8MB 上限、utf-16 positionEncoding、lifecycle/didOpen/didChange/didClose、诊断、注释保留格式化、语法补全、增量行索引);binding/ foreign_library(doris.parse.v1/format.v1/profile.v1/capabilities.v1 原始类型 ABI、doris.error.v1);parity/ 跨目标夹具;web/ Monaco 离线演示(相对资源、2.1/3.x/4.x profile、UI-SPEC 契约);vscode/ 标准 LanguageClient(tsc dist 构建、stdio、可配置 profile、不可用服务器降级);review 修复:write_all 偏移、分块 header 读 + 帧流水线、positionEncoding 字符串。

## Milestone Summary

**Decimal Phases:**

- None (no inserted decimal phases in this milestone)

**Key Decisions:**

- 无损 CST 为唯一数据模型,AST 视图投影(Phase 1)
- 手写递归下降 + Pratt,不用生成器(Phase 1)
- 官方发布文档为版本化语法权威(2.1/3.x/4.x profile,无 generic MySQL 回退)(Phase 1/2)
- 资源上限(ParseLimits)作为 parser-owned 不变式(Phase 1)
- 未支持语句显式 DORIS-PARSE-007,绝不静默跳过(Phase 2)
- print_lossless 与 canonical format 为独立操作,formatter 只导入 source/token/syntax(Phase 3)
- 格式化拒绝路径绝对化(DORIS-FORMAT-001,不掩盖解析诊断)(Phase 3)
- 序列化 schema 单一生产者(binding),Native/JS/Wasm 共享(Phase 4)
- parser/analyzer 边界:analyzer 独立包,parser 负向 gate(Phase 2/4)
