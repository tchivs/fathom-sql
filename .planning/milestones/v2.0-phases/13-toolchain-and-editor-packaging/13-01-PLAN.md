<objective>
把 Phase 11 已就绪的 Flink 语法与 CST 贯通到 formatter（TOOL-01 / D-01）：为 formatter/layout.mbt 增加 Flink 覆盖族 gate 与全套 Flink 语句族 clause_breaks/layout 分支，使每个 Phase 11 parser 可产出的 Flink 语句族要么被显式覆盖、要么按 refusal-first 拒绝（accepted=false、空输出、恰好一条 FATHOM-FORMAT-001、绝无部分输出）。本 plan 是 Phase 13 的 wave-1 tracer 切片：一条端到端路径 = 「flink 语句 → @api.format_with_ids → 覆盖族 gate → Flink family layout → 快照断言 + idempotence + 零诊断 reparse」；先以最小覆盖族证明 gate 与 refusal 通道，再横向扩展到全部 Flink 语句族与 flink-format 快照命名空间。

Purpose: TOOL-01 要求消费者能对受支持的 Flink CST 走 refusal-first 规范格式化，且与 lossless replay 分离；D-01 要求 layout 表覆盖 Phase 11 全部 Flink 语句族，未覆盖族视为编程缺口 → FATHOM-FORMAT-001 refusal。Research 现状（Pitfall 1）已实证：clause_breaks 对 Flink 专属族返回 `_ => []`，layout_statement 仍单行输出——正是 CONTEXT 标记的 silent-Doris-layout 危险。本 plan 把该缺口转为显式 gate + 完整覆盖表 + 快照命名空间。Doris 输出零漂移（先跑冻结 baseline，无 --update）。

Output: formatter/layout.mbt（flink_statement_covered + Flink 族 clause_breaks 分支 + layout_statement gate）、formatter/format.mbt + refuse.mbt（refusal 通道复用）、parity/flink_format_test.mbt（新 flink-format 快照命名空间 + idempotence/refusal 断言）。
</objective>
